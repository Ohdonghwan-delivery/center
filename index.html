배민 데이터 서버 연결

기존 Windows Electron 프로그램의 배민 로그인·세션 처리는 아이폰에서 실행되지 않습니다. 본인이 관리하는 인증된 HTTPS 서버에서 기사 현황을 JSON으로 제공하도록 연결해야 합니다.

배민 비밀번호·쿠키·세션 토큰을 여기에 입력하지 마세요. 서버에서 권한 검증이 필요하며, 인증 없이 공개되는 API는 사용하지 마세요.

홈 화면에 추가: 아이폰 Safari → 공유 → 홈 화면에 추가. iOS에서는 화면 잠금·백그라운드 전환 시 웹 GPS 전송이 중단될 수 있습니다.
